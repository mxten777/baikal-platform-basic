## Ⅰ. 현재 문제점

### 1. 보안 🔒
| 우선 | 항목 | 위치 |
|---|---|---|
| 🔴 | Supabase **anon key 가 repo 메모에 평문 노출** | `/memories/repo/baikal-platform.md` |
| 🔴 | `CRON_SECRET` 기본값이 빈 문자열 → 검증 우회 | `supabase/functions/sync-rss/index.ts:15`, `sync-youtube`, `sync-instagram` |
| 🟡 | `react-markdown` 출력 sanitize 미적용 (XSS 잠재) | `src/pages/lab/ArticleDetailPage.tsx`, `src/pages/projects/ProjectDetailPage.tsx` |
| 🟡 | Edge Function Rate limit 없음 | `supabase/functions/*` |
| 🟡 | Admin 폼 입력 검증 약함 (길이/URL/slug 중복) | `src/pages/admin/AdminContents.tsx` 외 |

### 2. 미완성·죽은 기능 🧩
- 🔴 `AdminSEO`, `AdminSettings`, `TopicDetailPage` 스텁
- 🔴 YouTube/Instagram 동기화: 코드만 있고 Secret/배포 미완료
- 🔴 OG 이미지 동적 생성: `generate-og-image` 호출되지 않음
- 🔴 댓글 / 뉴스레터 / 라이트모드 / i18n 0%
- 🟡 검색: `textSearch` 제목만, 태그·본문 검색 없음
- 🟡 콘텐츠 수정 시 slug 자동 재생성 안 됨 (`AdminContents.tsx:98`)
- 🟡 서버 페이지네이션 없음 (12개 클라이언트만)

### 3. 성능 ⚡
- 🟡 **Route-level code splitting 없음** (`src/App.tsx` 전부 정적 import)
- 🟢 React Query staleTime 5분은 설정됨 (`src/lib/queryClient.ts`)
- 🟡 이미지: `loading="lazy"`만, WebP/AVIF/srcset 없음
- 🟡 번들 크기 미측정

### 4. SEO 🔍
- 🔴 동적 OG 이미지 미연결
- 🟡 Sitemap / robots.txt 배포 확인 필요
- 🟡 Structured Data 일부 페이지만 적용
- 🟡 동적 경로 canonical URL 누락 가능

### 5. UX / 접근성 🎨
- 🔴 라이트 모드 0%, 다크 전용
- 🔴 a11y 부족 (aria, 키보드 네비게이션, 색상 대비)
- 🟡 로딩/에러/빈 상태 일관성 부족
- 🟡 토스트 알림 없음
- 🟡 실시간 폼 검증 없음

### 6. Admin 🛠
- 🔴 AdminSEO·AdminSettings 미구현
- 🟡 AdminDashboard analytics 실패 시 silent (`retry:1`)
- 🟡 다중 선택/일괄 작업/CSV export 없음

### 7. 데이터/백엔드 📡
- 🔴 YouTube/Instagram 인증·시크릿 미설정
- 🟡 RLS: `is_admin()`는 JWT metadata 의존, admin 계정 초기 세팅 절차 모호
- 🟡 `page_views` 퍼널/코호트 분석 불가
- 🟢 마이그레이션/기본 스키마 견고

### 8. 품질·DevOps 🧪
- 🔴 테스트 0% (Vitest/Playwright 미설정)
- 🔴 Sentry 등 에러 모니터링 없음
- 🔴 Core Web Vitals 모니터링 없음
- 🟡 Edge Function 로깅이 `console.log`만

### 9. 콘텐츠 전략 🌐
- 🔴 LinkedIn / Medium / GitHub 미지원
- 🔴 태그 자동 분류·콘텐츠 추천 0%
- 🟡 RSS 소스 1개(네이버 블로그)만 활성

## Ⅱ. 개선 방향 (우선순위)

### 🔴 P1 — 즉시 (1~2주)
1. anon key 재발급 + 저장소 정리
2. `CRON_SECRET` 강제 검증 (빈 값 차단)
3. `rehype-sanitize` 적용 (XSS 방어)
4. Sentry 통합 (`@sentry/react`)
5. YouTube/Instagram Secrets + 배포
6. AdminSEO 기본 구현 (URL별 메타·OG 오버라이드)
7. 동적 OG 이미지 연결
8. AdminContents 수정 시 slug 재생성 + URL/길이 검증

### 🟡 P2 — 중기 (3~6주)
1. Route-level `React.lazy` + `Suspense`
2. 검색 고도화 (Postgres `tsvector`, 태그·날짜 복합, 자동완성)
3. 서버 페이지네이션 (cursor 기반)
4. 이미지 파이프라인 (WebP/AVIF + srcset + aspect-ratio)
5. 토스트 알림(`sonner`) + zod 폼 검증
6. 라이트 모드 + a11y (WCAG AA)
7. Sitemap/robots/Structured Data 보강
8. GA4 + 커스텀 이벤트

### 🟢 P3 — 장기 (1~3개월)
1. i18n (한/영)
2. 댓글/좋아요 (Supabase Realtime)
3. 뉴스레터 (Resend/Mailchimp)
4. LLM 기반 자동 태그·요약·추천
5. LinkedIn / Medium / GitHub 채널 동기화
6. Vitest + Playwright + Lighthouse CI
7. PWA
8. Admin 일괄 작업 / 발행 예약
